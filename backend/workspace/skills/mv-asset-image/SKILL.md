# MV 资产出图规则

出图时把「风格头 + 下面这段规则 + 资产描述」拼起来发给图片模型。规则分两段，中间用 `---SCENE---` 分隔：
上半段给**人物**用，下半段给**场景**用。

## 人物（上半段）
四格人物定妆板，从左到右：
1. 第 1 格：正脸特写（只这一张有脸）
2. 第 2 格：正视全身，画面裁掉头部以上（无头）
3. 第 3 格：左侧全身，同样裁掉头部以上（无头）
4. 第 4 格：背面全身，同样裁掉头部以上（无头）

- 纯白背景；整张图**只出现一张脸**；同一个人、同一套衣服。
- 服装与配饰颜色照资产描述，**不许换款式、不许发明新衣服**。
- 不出现：镜子、屏幕、照片、海报、多个人、麦克风、手机、影子分身。

## 场景（下半段）
一张场景图：地点、时间、光线、色调、氛围都要有；**不要出现人物**。

## 提取失败时怎么调
- 人物脸不一致 → 先检查「人物描述」是不是有模糊词（或/可能），改成唯一值再出图。
- 场景里冒出人 → 把「不要出现人物」写进场景描述里再出一次。
