# MV 初步分镜写法

## 干什么
把用户写的「分镜提示词」（原始内容）扩写成一条**与歌等长**的粗分镜：从 0 秒到歌长秒数，分段覆盖整首歌，前后衔接、不重叠、不留空。

## 怎么写
- 每段只写「画面发生什么」：场景 / 动作 / 情绪，一句话。
- **不写景别、不写运镜**（那是「详细分镜」那一步的事）。
- 段长参考歌曲结构：前奏 / 主歌 / 副歌 / 桥段 / 尾奏；每段 5~20 秒，副歌段落可以短一点、密一点。
- 切点尽量落在**歌词句尾/换气处**（用户给了歌词时按句界分），没有歌词就按段落感分。
- 严格按用户给的原始内容写画面，**不要另外加情节、加人物、加场景**。

## 输出
只输出 JSON 数组，不要解释：
```json
[{"start":0,"end":8.5,"what":"开场雨夜的城市街道，主角撑伞独行"}]
```
