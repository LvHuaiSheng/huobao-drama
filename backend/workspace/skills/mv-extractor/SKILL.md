# MV 人物与场景提取指南

## 只提取写过的
只提取「分镜提示词」里真实出现的人物和场景。不要按常识补、不要发明没写的角色或地点。

## 人物字段
- **name**：简短中文名（用名字或代称，如「主角」「女主」）；同一个人的不同叫法合并成一个人。
- **description**：外貌 + 妆造，必须包含——
  - 发型发色、肤色、脸型气质
  - 服装：颜色 + 款式（例「深蓝色长款风衣」）
  - 配饰：颜色 + 类型（例「棕色皮质斜挎包」）
- **appearance**：只写脸/身形容貌（从 description 拆出来）
- **styling**：只写服装配饰（从 description 拆出来）

## 硬规矩（短剧那边同款）
- 每个属性只能有**一个确定值**：禁止「或」「可能」「皆可」「类似」这类模糊词。
- 颜色必须写"颜色+色相"（写 `grey` 会出纯灰，要灰棕必须写 `grey-brown`）；颜色词要能在提示词里对上。
- 不写人物的临时状态（受伤、换装、脏污）——只登记基准外观。

## 场景字段
- **name**：「地点+时间」（例「雨夜的城市街道」）
- **description**：地点、时间、光线、色调、氛围，写具体。

## 数量
一支 MV 通常 1-2 个人物、1-3 个场景。没有就返回空数组，不要凑数。

## 输出
严格 JSON，不要解释、不要 markdown 围栏：
```json
{"characters":[{"name":"","description":"","appearance":"","styling":""}],
 "scenes":[{"name":"","description":""}]}
```
